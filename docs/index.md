## How to use this documentation

1. Start with `01-project-overview.md` to understand the project intent.
2. Read `02-user-requirements.md` and `03-features.md` to align on functionality.
3. Use `04-tech-solutions.md` and `05-system-design.md` for architecture decisions.
4. Follow `06-ai-pipeline.md` and `07-implementation.md` during refactor.
5. Reference `08-api-design.md`, `09-database-design.md`, `10-testing.md`, and `11-benchmark.md` for implementation details.
6. Keep `roadmap.md` handy as the short, phase-level plan.
